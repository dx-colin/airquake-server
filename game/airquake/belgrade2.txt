2) Now start Quake2 normally.

3) After the demo is done playing, pull down the console by
pressing the tilde button (~ or `). Then type in the console
without the quotes: "game X" , where X is the directory where
you installed Airquake2. So if you installed Airquake2 into
a directory called AIRQ2, you would type "game AIRQ2".

4) Once Quake 2 has reset, type without quotes "map belgrade2"
and the level will start.

* Notes from the author *
Finally converted Bombing Belgrade to Airquake 2,
took much longer than I expected. Now I know I never
want to do another level conversion, especially if I
have to rename all the textures and change all the
entities. Atleast it's finished. I was not able to
put in all the features I wanted to add to the map.
Some of those were a bigger map and the ship moving
around. I found that the Quake 1 and Quake 2 limits
are about the same, its just that the Quake 2 engine
looks better. Actually to make the map playable on
a system like mine I had to remove a lot of the
destroyable buildings, so now only the main city
buildings can be destroyed. The good thing is
r_speeds are not bad and the level plays pretty good.
It's too bad though that I was not able to add
the clouds, they would have added a nice effect.
I hope everyone who plays this level enjoys it.
Please everyone support Airquake2, it really is a
great mod, they have done so much with the Quake 2
engine, all the plane physics and models and everything
just make it such a different experience. I hope
there are many more Airquake 2 maps to come.
You can find Airquake 2 at: 
(http://www.planetquake.com/airquake2/)
I have some future plans for other Airquake 2 levels
but they will have to hold as I work on a Half-Life
project called War Sector-X:
(http://www.millenium2048.co.uk/)
Enjoy!
